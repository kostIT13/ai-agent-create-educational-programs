# ИИ-агент для создания образовательных программ

Создайте ИИ-агента, который по запросу пользователя разрабатывает программу обучения по ИИ и формирует полный комплект материалов для курса. Решение должно учитывать заданные требования и референсы, определять структуру обучения, формировать карту компетенций, тестовые вопросы и задания для семинаров, а также готовить план и визуальные материалы для лекций.
